## Scope: 4 work items

### Item 1 — API hardening (Lightfield patterns)
1. **Idempotency-Key on writes:** Accept `Idempotency-Key` header (≤255 chars) on all POST endpoints
   (`/v1/agents`, spend writes, budget set). Same key within 24h → return the CACHED RESPONSE of the
   first request, never re-execute. Concurrent same-key in-flight → 409 `{"error":{"type":"idempotency_conflict",...}}`.
   Key too long → 400 `idempotency_key_too_long`. Scope keys per agent_id + operation type.
   Store in SQLite alongside ledger (table `idempotency(id, agent_id, op, response_json, created_at)`).
2. **Version header:** All `/v1/*` REST + MCP HTTP requests must include `AL-API-Version: 2026-09-01`.
   Missing/invalid → 400 with `{"error":{"type":"bad_request","code":"version_header"}}`.
   Current version constant in one place (config).
3. **Typed error envelope:** Every error response (REST + MCP tool errors) returns
   `{"error":{"type": str, "message": str, "code": str (optional), "param": str (optional)}}`.
   Map existing errors: auth→401, scope/cap→403, budget block→402 (keep), validation→400/422, not found→404.
   Codes: `invalid_agent_id`, `rail_not_allowed`, `agent_secret_mismatch`, `beta_cap_exceeded`,
   `version_header`, `idempotency_key_too_long`, `idempotency_conflict`.

### Item 2 — MCP meta-tools (agents self-serve)
Add to al_mcp_http.py + mcp_server.py:
- `ledger_api_docs(topic: str = "")` — returns markdown docs for: quickstart (curl), the 5 MCP tools,
  REST endpoints, error codes, idempotency usage. Topic filter: "quickstart"|"mcp"|"rest"|"errors"|"all".
- `ledger_examples(pattern: str)` — returns a complete runnable recipe for: "python_tracking" (x402/API-key
  spend tracking loop), "budget_enforcement" (set cap + handle 402), "weekly_report" (spend P&L aggregation),
  "retry_safe_writes" (idempotency-key pattern). Each example = full working Python snippet.
Docs content lives in a new `docs_content.py` (single source, also rendered by /llms.txt).

### Item 3 — Docs-as-distribution surface
- **README.md:** add "Connect AgentLedger" section at top: per-client one-liners (claude mcp add,
  codex mcp add, Cursor mcp.json merge, generic streamable-http URL), 3 example prompts
  ("Track my Claude Code spend", "Alert when any agent exceeds $50/day", "Weekly P&L report"),
  claim-on-first-write pitch (no OAuth, no API key, no signup).
- **recipes.md:** the 4 recipes from ledger_examples, rendered with real endpoints.
- **/llms.txt + /server.json:** update tool list with the 2 new meta-tools, bump version 0.3.0.

### Item 4 — Telemetry for new surfaces
